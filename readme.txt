DUBLIN BRIEF — Netlify-ready static site
1. Go to Netlify and sign in.
2. Choose Add new site → Deploy manually.
3. Upload the contents of this folder (or unzip the provided ZIP).
4. Netlify will generate a temporary *.netlify.app address.
5. Replace the demo headlines/images with your real editorial content before launch.

This is a visual prototype: the news, live feed, CMS, search, forms and social integrations are not connected yet.
